# Code of Conduct

## Our standard

Muraqib Core is a welcoming project for everyone. We expect all participants in issues, pull requests, discussions and reviews to:

- Be respectful and inclusive, whatever a person's background or experience level.
- Focus on the code and the idea, not the person.
- Give and accept constructive feedback gracefully.
- Help others learn and grow.

Harassment, personal attacks, discrimination, trolling and publishing other people's private information are not acceptable.

## Enforcement

Maintainers may edit or remove comments, close issues and pull requests, or block contributors who break this code of conduct.

To report a violation, email **aya.alaasel123@gmail.com**. Reports are handled privately, and the reporter's identity is kept confidential.
